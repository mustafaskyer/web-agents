Six steps, from an empty folder to a tool the agent cursor runs. This is how `examples/nextjs`
([Field Store on Next.js](/examples/nextjs)) is set up: Next.js 16, the App Router and Turbopack.

<div class="install-steps">

## Create a project

Skip this if you already have a Next.js app. The recommended defaults are what this page uses: TypeScript, the App
Router, Turbopack and the `@/` import alias.

```package-install
npx create-next-app@latest
```

## Install the packages

The agent cursor and the React bindings. Nothing else: the provider loads a WebMCP polyfill where the browser has
none, and the devtools panel in development.

```package-install
npm install @webmcp-agents/core @webmcp-agents/react
```

## Add the styles

Import the cursor's stylesheet in the root layout, next to your own.

```tsx app/layout.tsx
import "@webmcp-agents/core/cursor.css"; // [!code highlight]
import "./globals.css";
```

## Add the provider

`<WebAgentsProvider>` installs the cursor and registers your tools; in a browser without WebMCP it loads a polyfill
first, by itself, and in development it installs the devtools panel. It lives in a client component, which Next.js
still renders on the server with your page.

<include meta='title="app/providers.tsx"'>/_examples/nextjs/app/providers.tsx</include>

Wrap the page in it in the root layout. The highlighted lines are the ones you add.

<include meta='title="app/layout.tsx" {3,5,15}'>/_examples/nextjs/app/layout.tsx</include>

## Add your first tool

The action is one function with two callers: a person clicks the button, an agent calls the tool. `useWebTool`
registers the tool while the component is on the page. A plain `<button>` is enough: the cursor finds it by its role
and name.

<include meta='title="components/clear-cart.tsx"'>/_examples/nextjs/components/clear-cart.install.tsx</include>

Render it on a page. The page itself stays a Server Component.

<include meta='title="app/page.tsx"'>/_examples/nextjs/app/page.tsx</include>

## Run it

Start the app and open it.

```package-install
npm run dev
```

Open the devtools panel (bottom right, or **Alt+Shift+A**), expand `clear_cart` and press **Run**. The cursor flies
to **Clear cart** and waits there. Click the button yourself: the cart empties, and the tool answers "The cart is
empty."
