This is how `apps/nextjs` ([Field Store on Next.js](/examples/nextjs)) is built: Next.js 16, the App Router,
Turbopack, Tailwind v4 and shadcn/ui. Every step below is in that app.

## 1. Install

```bash
pnpm add @webmcp-agents/core @webmcp-agents/react @webmcp-agents/chat @webmcp-agents/vercel-api server-only
pnpm add -D @webmcp-agents/polyfill @webmcp-agents/devtools        # development only
pnpm add @ai-sdk/anthropic                                         # the SDK of your model's provider, server only
```

Next consumes the packages' built output (`dist`): there is no custom export condition in Turbopack, and this is the
published shape anyway. In this monorepo, `predev` builds the dependencies first.

## 2. Configuration

```ts next.config.ts
import type { NextConfig } from "next";

const nextConfig: NextConfig = {
  // React's taint APIs: a Server Component can't hand the API key to a client component by accident (step 6)
  experimental: { taint: true },
};

export default nextConfig;
```

The cursor stylesheet is served as a **static file**, not imported: Turbopack's CSS parser refuses Chrome's native
`:tool-form-active` pseudo-class inside the Tailwind pipeline. Copy it before dev and build:

```js scripts/copy-cursor-css.mjs
import { copyFileSync, mkdirSync } from "node:fs";
import { createRequire } from "node:module";

const require = createRequire(import.meta.url);
mkdirSync("public/web-agents", { recursive: true });
copyFileSync(require.resolve("@webmcp-agents/core/cursor.css"), "public/web-agents/cursor.css");
```

```json package.json
{
  "scripts": {
    "predev": "node scripts/copy-cursor-css.mjs",
    "dev": "next dev",
    "prebuild": "node scripts/copy-cursor-css.mjs",
    "build": "next build"
  }
}
```

```tsx app/layout.tsx
import "./globals.css";
import { Providers } from "./providers";

export default function RootLayout({ children }: LayoutProps<"/">) {
  return (
    <html lang="en">
      <head>
        <link rel="stylesheet" href="/web-agents/cursor.css" />
      </head>
      <body>
        <Providers>{children}</Providers>
      </body>
    </html>
  );
}
```

## 3. Tools and the agent

Tool definitions and the agent are plain data, imported by Server Components, client components and the route
handler alike. Tool **components** (forms) are client components: they need the DOM.

```ts tools/catalog.ts
import { defineWebTool } from "@webmcp-agents/react";

export const getCart = defineWebTool({
  id: "get_cart",
  description: "Read the cart: lines, promo code and totals.",
  annotations: { readOnlyHint: true },
  execute: (_input, ctx) => ctx.context!.cart.describe(),
});

export const catalog = [getCart /* , openProduct, goToPage */];
export const globalTools = catalog.map((t) => t.id);
```

```ts agents.ts
import { defineWebAgent } from "@webmcp-agents/chat/agent";

export const checkout = defineWebAgent({
  id: "checkout",
  description: "Finishes a purchase: reviews the cart, applies a promo code, places the order.",
  instructions: "Start with get_cart. Apply a promo code only when the user gave one. Then call checkout.",
  tools: ["get_cart", "go_to_page", "apply_promo", "checkout"],
});

export const shopper = defineWebAgent({
  id: "shopper",
  instructions: "Field Store sells apparel, accessories and home goods. Open a product before adding it.",
  tools: (tools) => tools.filter((t) => t.name !== "checkout" && t.name !== "apply_promo"),
  agents: [checkout],
});
```

```tsx tools/AddToCartForm.tsx
"use client";
import { useToolAnswer } from "@webmcp-agents/react";
import { useCart } from "@/lib/cart";

export function AddToCartForm({ product }: { product: Product }) {
  const cart = useCart();
  const { answer } = useToolAnswer();
  return (
    <form
      toolname="add_to_cart"
      tooldescription={`Add ${product.name} to the cart. Only on this product's page.`}
      toolautosubmit=""
      onSubmit={(e) => {
        e.preventDefault();
        const qty = Number(new FormData(e.currentTarget).get("qty"));
        answer(e.nativeEvent as SubmitEvent, Promise.resolve(cart.add(product.slug, qty)));
      }}
    >
      <input name="qty" type="number" min={1} defaultValue={1} toolparamdescription="How many to add, e.g. 2" />
      <button type="submit">Add to cart</button>
    </form>
  );
}
```

## 4. The client shell

One client component holds the cart store, the provider (with `usePathname()` so route-scoped tools follow soft
navigations) and the chat. The polyfill and the devtools load in an effect before the provider renders, so the first
tool registers on a `document.modelContext` that exists.

```tsx app/providers.tsx
"use client";
import { AgentChat, createCloudAdapter } from "@webmcp-agents/chat";
import { WebAgentsProvider } from "@webmcp-agents/react";
import { usePathname, useRouter } from "next/navigation";
import { type ReactNode, useEffect, useMemo, useState } from "react";
import { shopper } from "@/agents";
import { CartProvider, useCart } from "@/lib/cart";
import { catalog, globalTools } from "@/tools/catalog";
import "@webmcp-agents/chat/chat.css";

const ADAPTERS = [createCloudAdapter()];

function Shell({ children }: { children: ReactNode }) {
  const cart = useCart();
  const router = useRouter();
  const pathname = usePathname();
  const context = useMemo(() => ({ cart, navigate: (to: string) => router.push(to) }), [cart, router]);
  return (
    <WebAgentsProvider tools={catalog} global={globalTools} pathname={pathname} context={context}>
      {children}
      <AgentChat adapters={ADAPTERS} agent={shopper} />
    </WebAgentsProvider>
  );
}

export function Providers({ children }: { children: ReactNode }) {
  const [ready, setReady] = useState(false);
  useEffect(() => {
    void (async () => {
      if (!document.modelContext) await import("@webmcp-agents/polyfill/auto");
      if (process.env.NODE_ENV !== "production") {
        const { installWebAgentsDevtools } = await import("@webmcp-agents/devtools");
        installWebAgentsDevtools();
      }
      setReady(true);
    })();
  }, []);
  if (!ready) return null;
  return (
    <CartProvider>
      <Shell>{children}</Shell>
    </CartProvider>
  );
}
```

To render the chat with shadcn/ui's AI patterns instead of the built-in widget, install the `agent-chat` block
([Use your shadcn components](/guides/ai-elements)) and render `<AgentChatBlock adapters={ADAPTERS} agent={shopper} />`.

## 5. Pages are Server Components

```tsx app/product/[slug]/page.tsx
import { notFound } from "next/navigation";
import { findProduct } from "@/lib/catalog";
import { AddToCartForm } from "@/tools/AddToCartForm";

export default async function ProductPage({ params }: PageProps<"/product/[slug]">) {
  const { slug } = await params;
  const product = findProduct(slug);
  if (!product) notFound();
  return (
    <article>
      <h1>{product.name}</h1>
      <AddToCartForm product={product} />
    </article>
  );
}
```

## 6. `/api/chat` and the key

The route handler is the same handler the Vite apps deploy. The key lives in a `server-only` module and is
**tainted**: React throws if a Server Component ever passes that value to a client component.

```ts lib/env.server.ts
import "server-only";
import { experimental_taintUniqueValue as taintUniqueValue } from "react";

export const env = {
  anthropicKey: process.env.ANTHROPIC_API_KEY,
  model: process.env.WEB_AGENTS_MODEL ?? "anthropic/claude-sonnet-5-5",
};

if (env.anthropicKey) {
  taintUniqueValue("The API key never leaves the server. Call /api/chat instead.", process, env.anthropicKey);
}
```

```ts app/api/chat/route.ts
import { createVercelChatRoute } from "@webmcp-agents/vercel-api";
import { shopper } from "@/agents";
import { env } from "@/lib/env.server";

export const { GET, POST, OPTIONS } = createVercelChatRoute({ app: "nextjs", agents: [shopper], model: env.model });
```

```bash .env.local
WEB_AGENTS_MODEL=anthropic/claude-sonnet-5-5
ANTHROPIC_API_KEY=sk-ant-…
```

Never prefix a key with `NEXT_PUBLIC_`: those variables are inlined into the client bundle.

## 7. Deploy

A Vercel project with Root Directory `apps/nextjs` and the Next.js framework preset; the route is a function.
`vercel.json` sets `maxDuration: 60` for it. See [Deploy to Vercel](/guides/deploy).

## Where secrets live

| | |
|---|---|
| The API key | `process.env`, read by the route handler; `lib/env.server.ts` is `server-only` and taints the value. |
| The model | `WEB_AGENTS_MODEL` on the server, or `model` in the route. |
| Agent instructions | `agents.ts`, shared; the server reads them from its registry, the page sends only the id. |
| What the browser gets | the widget or the shadcn block, the page's tool descriptors, the conversation. No SDK, no key. |
