Permitted MIT adaptation from nikolas-sapa/ns-ui, revision `0bdd9f757bfc4b50b8d0c105403c46aecf1c4b66`, `registry/loud/hero-isobar-contours/component.tsx`. Copyright and permission notice are retained in `LICENSE.txt`. The upstream component and demo use only React imports and procedural DOM/Canvas/WebGL artwork; this source audit found no fetched image, font, model or texture asset. Geist is provided separately under its Fontsource license.

The original algorithm and demo are retained. Adaptations add default-on motion that settles within five seconds, a scoped scheduler for reduced-motion/offscreen/hidden behavior, and local semantic token lookup. No global browser API is replaced. This entry remains in review pending visual/state, reduced-motion, lifecycle, performance and consumer-install verification. Public reference evidence is local under `.local/references/ns-hero-isobar-contours/`; captures alone do not establish parity.
